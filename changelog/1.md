# A new era for Settlers 4 updates

The Settlers United mod files for Settlers IV now have a home of their own: balancing, plugin and everything that goes with it reach you **independently of the launcher** – no launcher update, no reinstall.

# What changes for you

- **Faster updates:** New balancing changes and plugin versions are there at your next start.
- **Stable or Preview:** Select the version you like in "Create new game" and in the Launcher-settings (Settlers IV, Tools) and choose between 'stable' or 'preview' to test upcoming changes before everyone else.
- **Secure:** All files are signed and verified before installation.
- **Replays:** This update was needed as starting point to support Replays. When joining a game or playing a replay, the launcher automatically loads exactly the version it was played with – replays stay playable after future updates. This ist yet **work in progress** as a **debugging feature** for now. A nice user interface to load Replays will follow soon.

This is the starting shot. It's going to get exciting. 🚀
